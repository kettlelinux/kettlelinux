A public test build for the AYN Thor. It runs from a microSD card; Android on the internal storage is not touched. It is the same system as the Odin 2 Portal's, set up for the Thor's two screens and controls.

## What's in it
- Game Mode with Valve's arm64 Steam client on the top screen, and a Plasma desktop across both screens
- The Plasma desktop inside Game Mode as well, from Desktop in Steam's library
- The bottom screen in Game Mode: the Performance app (frame rate, frame times, power, clocks, temperatures and the power settings), and a touch shell of its own (Plasma Mobile). Quick Access > Screens turns it off or on and sets its brightness.
- The AYN key opens Steam's Quick Access menu
- Atomic A/B updates from Steam's own Check for updates, with automatic fallback if an update fails to boot
- Starts through the U-Boot AYN ships on the device: no bootloader swap
- Kettle Installer: install to the internal storage next to Android, with a backup of the internal storage first
- Game Settings: per-game FEX, DXVK, vkd3d, Turnip and Proton settings, shared with other players, and .NET games run natively on ARM64
- Frame generation and upscaling plugins in Game Mode, off until enabled per game
- Power control from Steam's Performance panel: TDP, performance profiles, GPU clock and per-game fan curves
- Epic Games, GOG and Amazon Games in Game Mode, through the Game Stores plugin
- Battery charge limit and charge speed
- Lights: the rings around the sticks
- Crash reports in Quick Access, which you can share to report a crash on GitHub
- Android games in Steam, through Lepton, the Android layer Valve made for the Steam Frame
- Windows games outside Steam: Wine with FEX, DXVK and vkd3d-proton, plus Lutris and Heroic
- GE-Proton and Proton-CachyOS, and emulators and streaming apps from Flathub, installed from Kettle Welcome
- Hardware video decoding in Firefox (H.264, HEVC, VP9 and AV1), YouTube included
- A microSD card you put in becomes a Steam library, as on a Steam Deck

## Changes
- Screen refresh rate: the Power plugin has a 120 Hz switch for the top screen. Off holds it at 60 Hz in games and in Steam's menus alike, which uses less battery. The bottom screen can run at 30 Hz instead of 60 from Quick Access > Screens.
- Less battery with the bottom screen on: its touch shell no longer redraws when nothing changes (the GPU was kept awake 70% of the time, now 16%), the volume indicator no longer keeps the microphone and speakers running (about 0.15 W), and the Performance app pauses its readings while Steam has dimmed the screens.
- Fan while charging asleep: an option in the Power plugin's Battery section (off by default) runs the fan at a speed you choose while the Thor charges asleep.
- Less battery in sleep: an open sound stream no longer keeps the audio processor awake, and the stick lights and the controller are powered down until the Thor wakes.
- Headphones: unplugging them no longer leaves the system thinking they are still in.
- Wi-Fi: a scan that times out no longer locks up Wi-Fi.
- Rumble no longer gives a stray tap 5 seconds after it ends.
- A Vulkan game no longer holds up other programs drawing on the GPU at the same time.
- Kernel support for the unaligned atomic operations FEX uses to run x86 games.
- Decky plugins no longer show up twice after a plugin was updated from the store.

## Known issues
- The GPU can freeze. We're working on it.
- Early build: much of it has not been tested on a Thor yet. Not tested yet: starting from the ROCKNIX ABL, headphones, and power on battery (the Thor uses the Portal's power limits for now).
- The bottom screen in Game Mode is new. If it misbehaves, turn it off in Quick Access > Screens and please open an issue.
- The microSD card runs in its slower mode (about 13 MB/s), so games load more slowly from it than on the Portal.
- Android games: Android's status and navigation bars show, and can cover buttons in some games. Games that need Google Play services or buy things through Google Play inside the game don't work, and neither do games made only for x86 or for Android 12 and newer.
