A public test build for the Retroid Pocket 5, Kettle's first device with a Snapdragon 865. It runs from a microSD card; Android on the internal storage is not touched.

Starting it from the card needs Retroid's U-Boot, flashed once to the loader partition from a PC, or ROCKNIX's ABL if you already have it. Follow the RP5 install guide: https://github.com/kettlelinux/kettlelinux/blob/main/docs/INSTALL-RP5.md

## What's in it
- Game Mode with Valve's arm64 Steam client, and a Plasma desktop
- Atomic A/B updates from Steam's own Check for updates, with automatic fallback if an update fails to boot
- Kettle Installer: install to the internal storage next to Android, with a backup of the internal storage first
- Frame generation and upscaling plugins in Game Mode, off until enabled per game
- GPU overclock up to 750 MHz, as Steam's manual GPU clock, per game
- Game Settings: per-game FEX, DXVK, vkd3d, Turnip and Proton settings, shared with other players
- Crash reports in Quick Access, which you can share to report a crash on GitHub
- A microSD card you put in becomes a Steam library, as on a Steam Deck
- Chinese, Japanese and Korean text in games and the desktop

## Changes
- Run games natively on ARM64: Game Settings' Run natively on ARM64 runs a game's own code instead of its x86-64 build under FEX, for now the Linux builds of FNA, MonoGame, XNA and .NET games.
- Game Settings knows each game's engine (Unity, Unreal, Godot, GameMaker, .NET and more) and warns about anti-cheat. It suggests FEX settings that worked for other games on the same engine, applied only when you choose, and can apply verified settings for your device to games you haven't changed (off until you turn it on).
- Lights, a new plugin in Quick Access, lights the rings around the sticks: a color for both or each, the battery level, breathe or rainbow, with brightness and speed. They turn off when the device sleeps.
- Steam's saved login stays on the device it was saved on: a card moved to another device no longer has the two sign each other out ("Session Replaced"). Steam asks you to sign in there instead.
- RetroArch from Gaming Extras can download cores: its Core Downloader now offers libretro's ARM64 cores.
- The Kettle Installer stops, before changing anything, if another system (ROCKNIX, for one) sits after Android's storage, and says what to do.
- Linux 7.2.9, with its graphics, Bluetooth and arm64 fixes.

## Known issues
- Early build. Checked on an RP5: starting from the SD card through U-Boot, the screen, GPU and Vulkan, the gamepad, touchscreen, speakers, Wi-Fi, Bluetooth, the microSD card at full speed, and the GPU overclock in a game.
- Newer RP5s have a different screen (Visionox). If the screen stays black, put an empty file named visionox on the card's KETTLE partition from a PC, as the install guide shows. Not tested on a Visionox RP5 yet.
- Not tested yet: starting from ROCKNIX's ABL, installing to the internal storage, sleep (fixes are in, testing goes on), rumble, headphones and DisplayPort audio, and power settings on battery.
- The charger's readings (input current) are not accurate.
