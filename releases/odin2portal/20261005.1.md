A public test build for the AYN Odin 2 Portal. It runs from a microSD card; Android on the internal storage is not touched.

## What's in it
- Game Mode with Valve's arm64 Steam client, and a Plasma desktop
- The Plasma desktop inside Game Mode as well, from Desktop in Steam's library
- Atomic A/B updates from Steam's own Check for updates, with automatic fallback if an update fails to boot
- Starts through the U-Boot AYN ships on the device: no bootloader swap
- Kettle Installer: install to the internal storage next to Android, with a backup of the internal storage first
- Game Settings: per-game FEX, DXVK, vkd3d, Turnip and Proton settings, shared with other players, and .NET games run natively on ARM64
- Frame generation and upscaling plugins in Game Mode, off until enabled per game
- Power control from Steam's Performance panel: TDP, performance profiles, GPU clock and per-game fan curves
- Epic Games, GOG and Amazon Games in Game Mode, through the Game Stores plugin
- Battery charge limit and charge speed
- Lights: the rings around the sticks and the light by the power button
- Crash reports in Quick Access, which you can share to report a crash on GitHub
- Android games in Steam, through Lepton, the Android layer Valve made for the Steam Frame
- Windows games outside Steam: Wine with FEX, DXVK and vkd3d-proton, plus Lutris and Heroic
- GE-Proton and Proton-CachyOS, and emulators and streaming apps from Flathub, installed from Kettle Welcome
- Hardware video decoding in Firefox (H.264, HEVC, VP9 and AV1), YouTube included
- A microSD card you put in becomes a Steam library, as on a Steam Deck
- Back buttons M1 and M2

## Changes
- Game Stores, a new plugin in Quick Access: sign in to Epic Games, GOG and Amazon Games, browse your libraries, and install, update and uninstall games, which then play from your Steam library with Proton. Epic and GOG games keep their cloud saves and come with the DLC you own. Sign-ins and installs are shared with Heroic in the desktop.
- Battery charge limit: Steam's charge limit setting now works. At the limit the device runs from the charger while the battery rests, and charging starts again 5% below it. The Power plugin's Battery section, now at the top, adds a charge speed (Fast, Balanced or Slow) or a custom charge current.
- Games added to Steam from outside it (Game Stores games, Battle.net, emulators) now show in Game Settings, Frame Generation, Upscaling and Power, so they get per-game settings too.
- The desktop in Game Mode: Desktop in Steam's library opens the Plasma desktop inside Game Mode, with the same apps, settings and files as Desktop Mode, and no switch to Desktop Mode. The Steam button goes back to Steam with the desktop still open.
- Battle.net: Kettle Welcome (in the desktop or in Game Mode) downloads Blizzard's launcher, adds it to Steam as Battle.net and sets it to run with Proton-CachyOS (with Valve's Proton, its sign-in page shows no text fields).
- Less battery in Steam's menus: the screen runs at 60 Hz while no game is open, and a game capped at 30 or 60 fps runs the screen at 60 Hz. The memory and USB controller also power down when they can (a Portal idling in Steam's menus went from 1.8 W to 1.45 W).
- Run games natively on ARM64: Game Settings' Run natively on ARM64 runs a game's own code instead of its x86-64 build under FEX, for now the Linux builds of FNA, MonoGame, XNA and .NET games.
- Game Settings knows each game's engine (Unity, Unreal, Godot, GameMaker, .NET and more) and warns about anti-cheat. It suggests FEX settings that worked for other games on the same engine, applied only when you choose, and can apply verified settings for your device to games you haven't changed (off until you turn it on).
- Lights, a new plugin in Quick Access, lights the rings around the sticks (a color for both or each, the battery level, breathe or rainbow) and the light by the power button (the battery level, charging, or a color). The stick rings turn off and the power light dims when the Portal sleeps.
- Steam's saved login stays on the device it was saved on: a card moved to another device no longer has the two sign each other out ("Session Replaced"). Steam asks you to sign in there instead.
- Kettle starts through the U-Boot that AYN ships on the device: no bootloader swap, nothing on the device replaced. You set it once to start U-Boot instead of Android, as the install guide shows. The card also carries u-boot-ayn.img, to put U-Boot back if its partition was overwritten.
- RetroArch from Gaming Extras can download cores: its Core Downloader now offers libretro's ARM64 cores.
- The Kettle Installer stops, before changing anything, if another system (ROCKNIX, for one) sits after Android's storage, and says what to do.
- Linux 7.2.9, with its graphics, Bluetooth and arm64 fixes.

## Known issues
- The GPU can freeze. We're working on it.
- Hardware video decoding in Firefox is new. If a video stops, or plays sound over a still picture, please open an issue.
- Android games: Android's status and navigation bars show, and can cover buttons in some games. Games that need Google Play services or buy things through Google Play inside the game don't work, and neither do games made only for x86 or for Android 12 and newer.
- Early build: some features have not been tested on a Portal yet.
