A public test build for the Retroid Pocket Nova (Snapdragon 8 Gen 2). It runs from a microSD card; Android on the internal storage is not touched.

Starting it from the card needs ROCKNIX's ABL in place of Retroid's bootloader. Installing it needs a rooted Android, which Retroid's own build isn't; a Nova that already has ROCKNIX's ABL is ready. How it boots: https://github.com/kettlelinux/kettlelinux/blob/main/docs/RPNOVA.md

## What's in it
- Game Mode with Valve's arm64 Steam client, and a Plasma desktop
- The Plasma desktop inside Game Mode as well, from Desktop in Steam's library
- Atomic A/B updates from Steam's own Check for updates, with automatic fallback if an update fails to boot
- Kettle Installer: install to the internal storage next to Android, with a backup of the internal storage first
- Game Settings: everything set per game in one place, with tabs: FEX, DXVK, vkd3d, Turnip and Proton settings (shared with other players), power and refresh rate, upscaling and frame generation (off until enabled per game), and .NET games run natively on ARM64
- Power control from Steam's Performance panel: TDP, performance profiles, GPU clock and per-game fan curves, with Auto TDP on by default
- Epic Games, GOG, Amazon Games and Flathub's ARM64 apps in Game Mode, through Game Stores, and Amethyst Mod Manager
- Device Settings: battery charge limit and charge speed, lights, the screen's refresh rate, and system settings (start-up mode, SSH, factory reset)
- Crash reports in Quick Access, which you can share to report a crash on GitHub
- Android games in Steam, through Lepton, the Android layer Valve made for the Steam Frame
- Windows games outside Steam: Wine with FEX, DXVK and vkd3d-proton, plus Lutris and Heroic
- GE-Proton and Proton-CachyOS, and emulators and streaming apps from Flathub, installed from Kettle Welcome
- Moonlight, for streaming games from your PC, with its own plugin
- A microSD card you put in becomes a Steam library, as on a Steam Deck
- The screen at 60 or 120 Hz, laid out at a Steam Deck's pixel density
- Gyro and accelerometer for Steam Input, and the battery's own profile, from the Nova's own sensor firmware, copied from its Android on the first start
- Every button, the back paddles, and the face buttons by their labels
- The stick lights

## Changes
- Kettle 0.3.1, a fix release.
- A crash of the audio and sensor processor (the ADSP) no longer freezes the handheld. It keeps running, and the gyro comes back by itself within a minute; sound comes back after a restart.
- Starting a game after the handheld had slept could crash the sensor processor and freeze the handheld (seen with Windrose on the Odin 3 Portal).
- When the system crashes, it now restarts by itself after 10 seconds instead of staying frozen.

## Known issues
- This release's fixes were tested on an Odin 3 Portal; this build has not run on a Nova yet.
- After the audio processor has crashed and restarted, sound comes back only after a restart.
- If your Nova already restarts every minute or so since the 0.2.0 update, the update to 0.2.1 can't finish while it does: write the 0.2.1 image to the card again (this replaces what is on it), or open an issue on GitHub and we'll help.
- Remora is new: if a plugin misbehaves, or a Decky store plugin doesn't load, please open an issue.
- Early build. Checked on a unit: starting from the SD card and from the internal storage, A/B updates, the screen, touch and brightness, speakers, the stick lights, Wi-Fi and Bluetooth, every button, the gyro in a game, charging with the charge limit and charge speeds, the fan, the performance profiles, and sleep.
- Not tested yet: the headphone jack and microphone, the lowest brightness levels, the TDP range under a game (its limits are a placeholder), and the battery over a full discharge.
- The speakers use the Odin 2's amplifier tuning.
