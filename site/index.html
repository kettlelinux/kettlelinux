Each device has its own image: pick the one for yours. Write it to a 32 GB or larger microSD card. Android on internal storage is left alone. The Portal and the Thor start it through the U-Boot AYN ships them with, once it is set as the default boot: follow the install guide. The Retroid Pocket 5 starts it with a U-Boot flashed from a computer: follow the RP5 install guide. Once installed, updates come through Steam's own Check for updates.

A look around Game Mode

Kettle's own tools sit in Steam's Quick Access menu: press …, then the plug icon. The same tour opens on a new device, in Welcome.

Everything in Quick Access

Game Settings sets up each game, Game Stores brings in your other libraries, Device Settings looks after the device itself, and Crash Reports keeps what crashed. Each opens on what you need right now: Game Settings on the game that's running.

Game Settings: a tab for every part of a game

It opens on the running game, sets up any installed game before you start it, and All games holds the defaults. Everything is off until you turn it on for a game.

Game Stores

Epic Games, GOG, Amazon Games and Battle.net, installed and added to Steam with Proton (sign-ins and installs shared with Heroic on the desktop); Flathub's ARM64 apps by category, emulators and streaming apps among them; and Android games from F-Droid or an APK file.

Device Settings

Diagnostics: power draw, temperatures, clocks and everything about the device, from the bottom of Device Settings.

What you get

SteamOS experience

Valve's arm64 Steam client with its handheld Game Mode, and switching between Game Mode and Desktop.

Atomic A/B updates

Signed images installed from Steam, a read-only root, and automatic fallback if an update fails to boot.

Mainline kernel

Linux 7.2 with a pinned patch stack for the panel, gamepad, LEDs, haptics, microSD, Wi-Fi and suspend.

Frame generation and upscaling

Kettle's own frame generation, and SGSR 2, Arm ASR and FSR 2.2 upscaling, per game in Game Settings and off until you enable them.

Game Settings

A tab each for a game's FEX, graphics and Proton options, its fan, CPU and Auto TDP, upscaling and frame generation, plus settings other players found working: browse them.

Power control

TDP, performance profiles and GPU clock from Steam's Performance panel; fan curves, CPU limits and Auto TDP per game; a battery charge limit and charge speed.

Games outside Steam

ARM64EC Wine with FEX, DXVK and vkd3d-proton, plus Lutris and Heroic built for arm64.

Game Stores

Your Epic Games, GOG, Amazon Games and Battle.net libraries in Game Mode, added to Steam, with cloud saves and DLC for Epic and GOG; and Flathub's ARM64 apps, by category.

The desktop in Game Mode

Desktop in Steam's library opens the Plasma desktop inside Game Mode, with no switch to Desktop Mode. The Steam button takes you back.

Native ARM64 games

.NET games such as Terraria and Stardew Valley can run their own code on ARM64 instead of under FEX: one switch in Game Settings.

Device Settings

Charge limit, refresh rate, the stick lights, gyro, start-up mode, SSH and reset in one place, and a Diagnostics window with everything about the device.

Android games

Add an Android game to Steam and play it in Game Mode, through Lepton, the Android layer Valve made for the Steam Frame.

Crash reports

A report for every game or system crash, in Quick Access. Share one with your details taken out, and report it on GitHub from your phone.

Two screens on the Thor

Steam on the top screen and a touch shell on the bottom one in Game Mode, and both screens in the desktop.
